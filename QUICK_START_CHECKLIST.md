# Quick Start Checklist for Video Creation
## अनदेखी दास्तान - Episode 1

Follow this step-by-step checklist to create your video!

---

## **PHASE 1: PREPARATION (Day 1-2)**

### ✅ Step 1: Download Video Editing Software
- [ ] Download **DaVinci Resolve** (https://www.blackmagicdesign.com/products/davinciresolve/) OR
- [ ] Download **CapCut** (https://www.capcut.com/) OR
- [ ] Download **Shotcut** (https://shotcut.org/)
- [ ] Install and open the software
- [ ] Create a new project

### ✅ Step 2: Gather Free Stock Media
- [ ] Visit **Pexels Videos** (https://www.pexels.com/videos/)
  - [ ] Download: Dark road/highway night video
  - [ ] Download: Rain/storm effects video
  - [ ] Download: Bedroom interior
  - [ ] Download: Office space footage
  - [ ] Download: Evening/dusk road video

- [ ] Visit **Freesound.org** (https://freesound.org/)
  - [ ] Download: Heavy rain sound
  - [ ] Download: Thunder sound
  - [ ] Download: Car crash sound
  - [ ] Download: Footsteps sound
  - [ ] Download: Wind sound
  - [ ] Download: Door opening/closing sound

- [ ] Visit **YouTube Audio Library** (https://www.youtube.com/audiolibrary)
  - [ ] Download: Suspenseful background music
  - [ ] Download: Dramatic music for climax

### ✅ Step 3: Create Voice Narration
**Choose ONE option:**

**Option A: Text-to-Speech (FREE)**
- [ ] Go to **Google Text-to-Speech** (https://cloud.google.com/text-to-speech)
- [ ] Create account (free tier available)
- [ ] Enter dialogue for each character:
  - [ ] Tanya (young voice)
  - [ ] Tanya (adult voice)
  - [ ] Arjun (father - deep voice)
  - [ ] Naina (mother - gentle voice)
  - [ ] Grandmother (elderly voice)
  - [ ] Rahul (friend - casual voice)
  - [ ] Editor (authoritative voice)
  - [ ] Mystery Voice (spooky/echoing)
- [ ] Download all audio files as MP3
- [ ] Save in a folder: `Narration_Audio/`

**Option B: Hire Voice Actors (Paid)**
- [ ] Post job on **Fiverr** (https://www.fiverr.com/)
- [ ] Post job on **Upwork** (https://www.upwork.com/)
- [ ] Share script with voice actors
- [ ] Receive voice files
- [ ] Pay and download files
- [ ] Save in a folder: `Narration_Audio/`

## **PHASE 3: EFFECTS & POLISH (Day 5-6)**

### ✅ Step 16: Add Visual Effects
- [ ] Rain overlay (Scene 1, 2)
- [ ] Lightning flash (Scene 1, 2, 9, 10)
- [ ] Fog/mist effect (Scene 2, 9)
- [ ] Shadow effects (Scene 2, 9, 10)

- [ ] Transitions between scenes (fade, dissolve)

### ✅ Step 17: Color Grading

**Scene 1-2 (Night accident):**
- [ ] Dark blue color grade
- [ ] Low brightness
- [ ] High contrast
- [ ] Cool temperature

**Scene 3 (Bedroom night):**
- [ ] Deep purple/blue tones
- [ ] Very low brightness
- [ ] Moody atmosphere

**Scene 4-5 (Morning):**
- [ ] Warm golden tones
- [ ] High brightness
- [ ] Natural sunlight feel

**Scene 6-8 (Office):**
- [ ] Natural/neutral color
- [ ] Normal brightness
- [ ] Professional look

**Scene 9-10 (Evening/dusk):**
- [ ] Orange/purple gradient
- [ ] Medium brightness
- [ ] Atmospheric/mysterious feel

### ✅ Step 18: Audio Mixing & Balance
- [ ] Adjust narration volume (should be loudest)
  - Target: -6dB to -3dB
- [ ] Adjust SFX volume (supporting)
  - Target: -12dB to -9dB
- [ ] Adjust music volume (background)
  - Target: -18dB to -15dB
- [ ] Add fade-in at beginning
- [ ] Add fade-out at end
- [ ] Remove audio clicks/pops
- [ ] **Test:** Listen on headphones for issues ✅
- [ ] **Test:** Listen on phone speakers ✅

### ✅ Step 19: Add Text Overlays

- [ ] Add credits at end:

## **PHASE 4: FINAL REVIEW (Day 7)**

### ✅ Step 20: Quality Check
- [ ] Play entire video from start to finish
- [ ] Check audio sync (narration matches lips if visible)
- [ ] Check all dialogue is clear and audible
- [ ] Check SFX are properly timed
- [ ] Check music doesn't overpower dialogue
- [ ] Check color grading is consistent per scene
- [ ] Check transitions are smooth (no jarring cuts)
- [ ] Check no video glitches or artifacts
- [ ] Check text is readable (good font size & contrast)
- [ ] Check total duration (should be 16-18 minutes)
- [ ] Check aspect ratio is 16:9 throughout
- [ ] Check intro and outro are strong

### ✅ Step 21: Export Settings

**In DaVinci Resolve:**
- [ ] Go to "Deliver" tab
- [ ] Format: **H.264**
- [ ] Resolution: **1920x1080** (1080p)
- [ ] Frame rate: **24fps** or **30fps**
- [ ] Codec: **H.264 (AVC)**
- [ ] Quality: **High Quality**
- [ ] Audio: **AAC Stereo, 48kHz**
- [ ] File name: `Andekhi_Dastan_Episode_1_Final.mp4`

**In CapCut:**
- [ ] Click "Export"
- [ ] Resolution: **1080p**
- [ ] Format: **MP4**
- [ ] Quality: **High**
- [ ] File name: `Andekhi_Dastan_Episode_1_Final.mp4`

### ✅ Step 22: Export Video
- [ ] Set destination folder
- [ ] Click "Export" / "Render"
- [ ] Wait for export to complete (30-60 minutes typical)
- [ ] Verify file created successfully
- [ ] Check file size (should be 500MB-2GB for 18 min video)
- [ ] Test play exported video in media player

## **Troubleshooting**

| Problem | Solution |
|---------|----------|
| Audio/Video out of sync | Re-sync in timeline, adjust timing |
| Audio too quiet | Increase volume slider, normalize audio |
| Video laggy during playback | Lower preview resolution, proxy files |
| Artifact/glitch visible | Remove clip, re-import, replace |
| Text not readable | Increase font size, add background/shadow |
| Export very slow | Lower resolution temporarily, upgrade computer |
| Music too loud | Reduce volume to -15dB or lower |
| Video too dark | Increase brightness/exposure in color grading |
| Dialogue unclear | Re-record narration or use clearer TTS voice |

## **Tips for Success** 💡

✅ Start with small scenes first
✅ Save frequently (every 15 minutes)
✅ Use headphones to check audio quality
✅ Take breaks to avoid eye strain
✅ Watch tutorials if stuck on a feature
✅ Don't be perfectionist on first attempt
✅ Learn as you go - each episode gets easier!
